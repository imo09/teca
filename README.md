# teca

Lettore calmo di pagine HTML, Markdown, testo, immagini, libri EPUB e FB2, fumetti CBZ, tabelle CSV, dati JSON e XML e codice. Versione 1.5.
I file restano sul dispositivo: teca non li invia da nessuna parte e ricorda solo i loro nomi e il punto di lettura.

Pubblicata su https://teca.nautargo.com con GitHub Pages. Un'app nautargo.
